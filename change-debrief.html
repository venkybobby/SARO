FND-052 — remove operator's fake "Avg Score" KPI tile

Follow-up to STORY-413 (Dashboard placeholder KPIs). User directive: "Don't want to show fake scores in demo."

Context

STORY-413 removed 8 named hardcoded KPI tiles from the Dashboard. During that build, a 9th fake tile was found — operator persona's "Avg Score" (hardcoded 41) — but it had no placeholder: true flag and wasn't in the story's named list, so it was logged as FND-052 (status: open) rather than fixed: its intended semantics (average of what, over what window?) were never specified. The user has now resolved that open question by directive — no invented semantics, no fake number, remove it.
